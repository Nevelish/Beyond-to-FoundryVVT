Import your characters easily

Cobalt Cookie

Copy your DnD Beyond cobalt cookie for authentication

Character Data

Copy character data from the current DnD Beyond character page

Instructions

  1. Navigate to your character page on DnD Beyond
  2. Click "Copy Cobalt Cookie" to copy authentication
  3. Click "Copy Character Data" to copy character information
  4. Paste the data into FoundryVTT's character importer
